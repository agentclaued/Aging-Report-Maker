G. OPTION 66 IN DETAIL (the one used on the office PC)
-----------------------------------------------------------------
Install (Admin Command Prompt, shows errors on screen):
  powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Repos\walmart_Ageing_Office pc_Ans\App Control Center\window_autostart.ps1" -Action Install
  - creates venv if missing, installs requirements.txt into it
  - asks for the Windows password of the account that will run the task (needed to run at boot before login).
    No password on the account = the task cannot be created.
  - creates task Tools-walmart_summary with 3 triggers:
        at PC startup (45 s delay)  |  at every logon  |  repeats every 10 minutes
    plus: StartWhenAvailable, MultipleInstances IgnoreNew (a 2nd copy is ignored while one runs),
    restart on failure (999 times, 1 min apart)
  - the task runs: cmd /k with a loop that starts uvicorn again 5 seconds after it stops
  - so after boot, restart, crash, or a closed window the app is back within 10 minutes
Uninstall:
  powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Repos\walmart_Ageing_Office pc_Ans\App Control Center\window_autostart.ps1" -Action Remove
Start now:   schtasks /Run /TN Tools-walmart_summary
Verify:      schtasks /Query /TN Tools-walmart_summary
             netstat -ano | findstr :8507
             curl http://localhost:8507/_stcore/health
A visible window only appears if that user is logged in. Without it the app still runs;
use netstat / curl / the browser to verify.

-----------------------------------------------------------------
1. _delete_file_after_download(path)   NEW helper (near _mark_amazon_download_complete).
   Deletes a generated report from output\ after the browser finished downloading it.
   Used as a Starlette BackgroundTask on: the Wal Mart status workbook response, the Amazon workbook
   (inline and /download/amazon-account-sheets), and the Regular Accounts per-person report response.
   NOT applied to: /download/step-01, /download/step-01a, /download/latest-tables (re-download buttons).

   (form field "amazon_accounts" from the three checkboxes). It is passed to
   AmazonAccountSheetProcessor(...).process(inquiry_path, company_output_dir, amazon_accounts).
4. @app.get("/_stcore/health")   NEW alias placed on the /health function, so the hub portal sees the app as Online.
Related files changed for the same features:
   app\adapters\full_ageing_source.py          NEW: reads sheet "Full Ageing", finds the header row (Acct + Ref Type, first 15 rows), filters Acct.
   app\adapters\wallmart_python_processor.py   _read_source(): if the workbook has a Full Ageing sheet, use its rows for

   app\adapters\amazon_file_processor.py       process(file, out, accounts=None): Full Ageing rows for the ticked accounts
                                               (default AM9285, AM9286; ME9145 optional); otherwise old behaviour.
   templates\index.html                        Amazon upload box: fieldset with 3 checkboxes (AM9285, AM9286 checked; ME9145 unchecked).

O. WHAT THE .ps1 FILES DO (and what was fixed)
-----------------------------------------------------------------
stop_background.ps1
   $projectRoot = parent of the control folder; reads PORT from app_runtime.env (default 8040).
   1) taskkill /T /F on any process whose command line contains this folder's background_tray.pyw.
   2) finds the listener on the port and kills it only when it (or a parent, up to 4 levels) is the "app.main:app" uvicorn.
boot_autostart.ps1 (22)
   param -Action Install|Remove. Task WalMartSummary_Boot as SYSTEM at startup (45 s delay), hidden, no restart on failure,
   removes the login shortcut, adds a tray-only (--attach) shortcut at login.
boot_recovery_autostart.ps1 (55)
   Task WalMartSummary_BootRecovery as SYSTEM at startup (45 s), restarts every 1 min on failure (999 times);
   removes the 22 task and the 33 shortcut so only one starter exists.
window_autostart.ps1 (66)
   Creates venv + installs packages, asks for the Windows password, task Tools-walmart_summary as that user with triggers
   startup (45 s) + logon + every 10 minutes, StartWhenAvailable, IgnoreNew, restart on failure;
   command = cmd /k with a uvicorn restart loop.
Fixes applied to all three install scripts:
   - variable $action renamed to $taskAction (PowerShell variables are case-insensitive, so $action clashed with the -Action
     parameter and caused "MSFT_TaskExecAction is not a valid value for the Action variable").
   - root path is now one level up (..), not two.
Change the 66 repeat interval:  in window_autostart.ps1 edit  -RepetitionInterval (New-TimeSpan -Minutes 10)  then re-run the installer.
Change the port or host: edit app_runtime.env (HOST, PORT), re-run the installer if the port changed, add the new firewall rule, update tools.json.
